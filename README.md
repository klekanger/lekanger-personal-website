# Lekanger.no - personal web site

This repo contains the source code for Kurt Lekanger's personal web site.

## Stack

- Tanstack Start
- Sanity
- Tailwind CSS
- Shadcn/ui

## Monorepo structure

The project is a pnpm + Turborepo monorepo:

- `apps/frontend` — TanStack Start frontend
- `apps/studio` — Sanity Studio CMS and schema definitions
- `packages/shared` — Shared code, including TypeScript types autogenerated from Sanity schemas and shared between the frontend and studio workspaces
